# 單腳測試：先用操作台讓一隻腳小轉一下

> 2026-09-07：目前 36 V 吊掛測試的保護門檻已調整，請以[吊掛測試保護調整](suspended_safety_tuning_zh_TW.md)及現場設定為準；本文件下方的舊數字可能仍描述初始保守設定。

[回到入口](README.md)｜[腿部啟用／屏蔽](orin_multileg_operation.md)｜[監控與錄製](rinbo_monitor.md)

日常操作先看 [Control Panel 簡明教學](control_panel_zh_TW.md)。主選單 **8** 可直接查看、屏蔽或解除屏蔽腳，不必另外輸入 ROS 指令。

適用：機身可靠固定、腳懸空時的主馬達測試。第一次先用「小轉一下 +5°」，之後再試速度與相位。

操作台依 **R-Slip v6.6** 整合 sbRIO → Bridge → 電源 → 校正流程。
位址已填好：sbRIO `192.168.30.254`、Jetson `192.168.30.8`、ROS domain `99`。

## 打開操作台

在 **Jetson** 終端機貼上：

```bash
cd /home/jetson/rinbo_ros_ws
./robot.sh
```

啟動選單不會上電。直接輸入 **`L2 +5` → `3` → `y`**，會自動連線、只校正 L2，再讓 L2 小轉 5°。同設定成功後再選 **3** 就直接重做。想逐項填設定仍可選 **2**。
本操作台與 Windows 啟動器擇一使用，不要同時操控。

## 快速調整，不用一直走選單

在主選單輸入下列指令，只會改設定；選 **3** 才執行。

| 輸入 | 用途 |
|---|---|
| `L2 +5` 或 `L2 -5` | 只選 L2，從目前位置正轉／反轉 5° |
| `L2 v 10` | 只選 L2，每秒轉 10°；速度上限不足時一併提高，出力不變 |
| `L2 a 90` | 只選 L2，移到校正零點的 90° |
| `L2 p 180 10` | 只選 L2，先對齊 180°，再每秒轉 10° |
| `time 5` | 保持／勻速時間改成 5 秒 |
| `pwm 30` | 逐腳動作出力上限改成 30 |
| `speed 20`、`acc 20` | 分別設定速度上限與加速度 |

換設定後第一次執行輸入 `y` 或「開始」；成功後，同設定重做只需選 **3**。校正失效或現場設定變更時會重新列出內容，不能以舊確認跳過新的校正。連線正常時，選 3 不再重跑 SSH 啟動檢查；選 1 仍可做完整通訊檢查。

**校正／動作中按 `Q`、空白鍵、`Esc` 或 `Ctrl+C` 停止，不用按 Enter。** 程式會停止並嘗試關電；實際停止仍需通訊及控制器處理時間。

## 不知道下一步做什麼，或數字怎麼填

**直接在主選單輸入 `h`**，就會看到每一步的白話說明。
想從簡單設定開始，**輸入 `r`**：程式選一隻目前可用的腳，套用「從現在小轉 +5°」的入門範例。
這一步只存設定，之後仍要選 `3`、確認並輸入「開始」才執行。

填數字時，畫面會同時寫出用途、入門建議、可填範圍，以及 **直接 Enter 會採用的值**。
Enter 會沿用顯示值，可能是你以前改過的設定；要回到入門範例請用 `r`。

| 數值 | 入門起點 | 白話意思 |
|---|---|---|
| 保持／勻速時間 | 3 秒 | 到位後保持多久，或固定速度轉多久；另加對齊與加減速 |
| 速度上限 | 10 度／秒 | 目標速度最多到多少；每隻腳的旋轉速度另填 |
| 小轉一下的角度 | +5 度 | 從現在再轉 5 度；-5 是反方向 |
| 按速度旋轉 | 5 度／秒 | 固定速度轉一整圈約 72 秒 |
| 起始相位 | 單腳先用 0 度 | 先對齊再轉；兩腳 0、180 是相差半圈，可能先大幅對齊 |
| 逐腳動作出力上限 | 20 | 限制驅動出力，不是速度、伏特或百分比 |
| 加速度 | 10 度／秒² | 目標速度改變多快；從 0 到 10 度／秒至少約 1 秒 |

「移到角度」以校正零點為基準，填 5 不等於從現在只轉 5 度；第一次試動建議選「小轉一下」。
上述是程式的入門設定，是否到位仍由回讀檢查。可填範圍只是程式允許的範圍，先從入門值開始。
這些動作限制用於校正後的逐腳動作；校正使用現場設定，只尋找本次選中腳的零點。

## 選 1：把通訊開起來

**已設定此位址的密碼時會自動登入，不用每次輸入。** 密碼保存在 Jetson 的 `~/.config/rinbo_control/ssh/192.168.30.254.password`，檔案只允許目前使用者讀寫，不放進程式碼、指令列或操作日誌。刪除該密碼檔可恢復手動輸入；換到另一個 sbRIO IP 時不會自動使用原位址的密碼。
若自動登入遇到尚未信任的主機，先在終端機執行 `ssh admin@192.168.30.254` 核對並確認主機指紋，再回操作台重試。

程式自動處理：

```text
檢查 Jetson 網卡 → SSH 登入 sbRIO → 設定函式庫路徑與 IP
→ 核對 FPGA 檔案 SHA-256
→ 啟動 core，確認 50051 監聽
→ 啟動 FPGA driver，確認 Session opened (Success)
→ 啟動 Jetson Bridge → 確認 motor/state 與 power/state 都有新資料
```

**看到「通訊就緒」才算成功；本次還沒有上電。**
已在跑且設定相符的服務會沿用。重複選 1 不重啟服務、不重新上電、不重新校正。
既有 driver 先核對程序身分、IP、工作目錄，再以實際 ROS 回讀確認通訊。

| 畫面錯誤 | 要處理什麼 |
|---|---|
| Permission denied | sbRIO 登入未通過，使用 sbRIO 的 admin 密碼 |
| CORE_LOCAL_IP／CORE_MASTER_ADDR 不符 | sbRIO 上仍有使用舊 IP 的程序，先處理舊通訊 |
| FPGA SHA-256 不符 | FPGA 檔案不符 v6.6，不能跳過 |
| Open Failed／-63101 | FPGA 開啟失敗，先處理 sbRIO 問題 |
| 50051 拒絕連線 | core 未正常提供通訊服務，查看 sbRIO 日誌 |
| Bridge 已開但沒有新回讀 | 檢查 driver，不能繼續上電 |

## 選 2：設定這次怎麼動

例如讓 L2 小轉一下：

| 畫面問什麼 | 填入 |
|---|---|
| 要使用哪些腳 | `2` 代表 L2；`2 5` 代表 L2、R2，也接受腳名 |
| 這隻腳怎麼動 | 選 `1`：小轉一下 |
| 從現在轉幾度 | `5`；反方向填 `-5` |
| 保持／勻速時間 | 最後填 `3` 秒；Enter 沿用畫面顯示值 |

出力、加速度與速度上限集中在主選單 **7**。設定速度動作時，若指定速度超過原上限，會一併提高速度上限，出力不變。想直接用範例可選主選單 **9**，依序選腳與動作種類。

**「小轉一下 +5°」是從現在再轉 5°。** 例如目前在 170°，目標是 175°。

每隻腳能各自選：

- **小轉一下：** 從現在的位置轉指定角度，限制 ±30°。
- **移到角度：** 移到相對校正零點的角度，可能大幅轉動。
- **按速度旋轉：** 每秒轉幾度，負數為反方向。
- **按相位旋轉：** 先對齊相位再轉；180° 是半圈。想維持固定相位差，速度須相同。

未選的主馬達停用。禁用名單直接讀 Orin 現場設定，禁用腳不能選，不會自動解除屏蔽。

## 選 3：確認後執行

先可靠固定機身、讓腳懸空，清空轉動範圍並準備實體急停。
一般模式會列出動作與校正範圍。**第一次／更改設定後，輸入「開始」或 `y` 才執行；直接 Enter 取消。同設定成功後，再選 3 會直接重做。** 人在現場連續調機可選 **14 → 1**；之後按 **3** 就開始，不再多問一次。選 **13** 可單獨快調出力，選 **9** 套用動作會保留已調好的出力、時間及加速度，詳見[日常操作教學](control_panel_zh_TW.md)。

首次上電依 v6.6 接好：

```text
確認沒有其他馬達控制程式 → 全部關電並確認
→ Digital → Signal → 確認馬達輸出=false、命令發布者=0
→ Relay（18–30 V、未禁用腿電流小於 3 A、連續 3 筆有效回讀）
→ 校正完成並確認馬達停用 → 執行你的逐腳動作
→ 確認馬達停用，關 Relay、保留感測器供電
```

感測器已保持供電時，不會重做 Off／Digital／Signal；Relay 已開時只核對回讀，不重送上電。
每個電源指令最多等 8 秒尋找 Bridge，找到就繼續，不反覆上電重試。

若顯示「正在辨識 Bridge 的資料來源」，是校正程式自己的 ROS 連線仍在準備，最多等待 8 秒。
這段等待尚未建立馬達命令發布者；來源確認後，才開始原有的回讀與握手檢查。
若持續無法辨識、出現錯誤來源或重複發布者，仍會停止並嘗試關電。

**操作台只校正本次選中的腳。選 L2，就不會等 L3 的零點；選 L2、R2，就校正這兩隻。**
其他主馬達不啟用、不歸零；未選中伺服保持其回讀位置。伺服控制與供電共用，這不是逐顆伺服斷電。
同一個操作台內，這些腳的校正有效且感測器供電與回讀持續正常，就可沿用校正。改選未被目前校正紀錄涵蓋的腳，會校正這次選的腳；每次新校正會取代上一份紀錄。
全部關電、回讀中斷或設定變更後需重新校正。

**如果一直顯示校正中：** 看「已完成幾隻」和「仍在等哪隻」。例如 `已完成 4／5 隻；已跳過 1 隻；仍在等：L3（尋找零點訊號）`，表示四隻已完成，但 L3 還沒回報到位。Hall 是偵測零點的感測器；腳看起來轉到正確位置，仍需收到它的訊號，以及停穩後的位置歸零回讀。

操作台仍遵守共用設定 `/home/jetson/redrhex_site/rinbo_fsm_disabled_leg.yaml` 的 `disabled_legs`；選腳不更改共用屏蔿名單。舊紀錄中的 `4／5、等待 L3` 是全腿校正；新版只選 L2 時不會等待 L3。若直接執行不帶 `--plan` 的 `ros2 run rinbo_fsm rinbo_cali`，仍是校正全部啟用腳，供原來的 Standing／Tripod 流程使用。單腳校正完成紀錄不能當作全機已校正。

保持／勻速時間另外加上對齊、加減速與收尾時間。沒到位或跟不上目標時先處理原因，不要直接加大出力。

## 停止與重試

| 操作 | 結果 |
|---|---|
| 校正／動作中按 `Q`、空白鍵、`Esc` 或 Ctrl+C | 不用 Enter；停止本次動作，嘗試全部關電，保留通訊 |
| 正常完成 | 關馬達電源、保留感測器，方便下一次調整 |
| 選 `4` | 全部關電，保留通訊 |
| 選 `0` | 確認關電 → 停本工具的 Bridge → 停本工具的 driver／core → 離開 |

失敗後先處理原因，再由你選 3 重試，程式不自動重跑。
沿用外部啟動的通訊程序時，本工具不會停止它們，最後由原啟動器完成停止。
關電未知或停止未完成，不能當成成功；使用實體急停／切斷動力電源，保留通訊供排查。
停用驅動不會鎖住腳，也不保證立即消除慣性。

本工具採用 v6.6 **Part B 的啟動與檢查順序**，並保留逐腳測試功能。
Windows 的 Standing／Tripod 與「失敗後仍保留 Relay」局部重試，仍由原 Windows 啟動器負責。
本工具失敗會嘗試關電，不將失敗動作記成成功。

## 日誌、演練與更新

- Jetson 日誌：`~/.local/state/rinbo_control/logs/`。
- sbRIO 日誌：`/home/admin/.local/state/rinbo-control/<本次編號>/`，啟動時會印出完整路徑。
- Jetson 程序紀錄：`~/.local/state/rinbo_control/sbrio-session.json`，用於下次核對 sbRIO 程序，不含密碼。不要刪除來繞過停止。
- 選 `5` 看狀態；選 `6` 改 IP。有舊位址的通訊紀錄時，先用原位址完成停止。
- `./robot.sh --demo`：不連線、不上電的選單演練。
- `./robot.sh --check`：只檢查安裝，不連設備。

只有首次安裝或修改程式後才需要編譯；請先停止實機動作。改角度、速度不需重編：

```bash
cd /home/jetson/rinbo_ros_ws
source /opt/ros/humble/setup.bash
source install/setup.bash
CMAKE_BUILD_PARALLEL_LEVEL=2 MAKEFLAGS=-j2 colcon build --packages-select rinbo_fsm rinbo_control redrhex_lowlevel_bridge --parallel-workers 1
```

## 自己改 YAML，或找程式

操作台的選單會保存自己的動作設定。下面的 YAML 是直接執行 `rinbo_manual --plan` 時使用的範例；不要以為改範例檔就會改到選單中的動作。

| 想改什麼 | 去哪裡找 |
|---|---|
| 單腳目標角度 | [manual_single_leg.yaml](../src/rinbo_fsm/config/manual_single_leg.yaml)；預設 L2 移到校正零點後 5°，不是從現在再轉 5° |
| 每隻腳不同速度 | [manual_velocity.yaml](../src/rinbo_fsm/config/manual_velocity.yaml) |
| 相同速度、不同相位 | [manual_phase.yaml](../src/rinbo_fsm/config/manual_phase.yaml)；相位是旋轉一圈中的位置，180° 就是半圈 |
| 中文選單 | [console.py](../src/rinbo_control/rinbo_control/console.py) |
| 通訊、上電、校正順序 | [runtime.py](../src/rinbo_control/rinbo_control/runtime.py)、[sbrio.py](../src/rinbo_control/rinbo_control/sbrio.py) |
| 主馬達控制與軌跡 | [rinbo_manual.cpp](../src/rinbo_fsm/src/rinbo_manual.cpp)、[manual_motion.hpp](../src/rinbo_fsm/src/manual_motion.hpp) |
| 校正流程 | [rinbo_cali.cpp](../src/rinbo_fsm/src/rinbo_cali.cpp) |

只選目前未屏蔽的腳。相位範例可能列出多腳，先刪除這次不測的腳；速度 0 仍會保持位置，省略該腳或 `mode: off` 才是此次停用。

需要直接寫 YAML 或逐條下指令時，再看 [手動控制技術參考](reference/manual_control.md)。平常用本頁的操作台即可。
