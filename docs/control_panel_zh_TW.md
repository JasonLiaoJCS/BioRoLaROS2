# 機器人 Control Panel：日常操作

## 目前參數與調參方式（2026-09-09 revision 15 之後）

操作台每次更新畫面都向原生設定工具讀取目前有效值，顯示各模式的 KP、KD、K_FF、PWM 及設定版本。逐腳動作另顯示「計畫上限與現場 Manual 上限取較小值」的實際上限；計畫 80 並不表示 Tripod 被限制為 80。

已保存的標準為 Calibration／Standing／Manual 上限 500、Tripod 上限 3300，控制速度濾波皆為 5 ms。Standing 停穩時間為 0；Tripod 額外 slew 關閉。完整值與恢復方法見[重要參數基準](IMPORTANT_PARAMETER_BASELINE.md)。現場之後可以依需求調整，連線不要求數值等於此標準。

- **7** 修改本次逐腳計畫，**13** 查看／採用目前現場 Manual 上限。
- **15** 讀取並修改各階段到位／追蹤設定；**r** 明確恢復該頁的 `standard_20260909_r15` 值，先預覽、再按 Enter 儲存。進入頁面不會自動恢復標準。
- 支援範圍內的調參可以繼續使用；仍保留數字格式、原生允許範圍、腿位屏蔽、供電／通訊保護與同時修改檢查。設定變更使舊完成紀錄失效時，依流程重新校正即可，不需改回舊值才能連線。
- `python3 tools/parameter_baseline.py check` 是手動比對工具，並非操作台的啟動或連線門檻。

若遇到 L1 在 Standing 持續旋轉、尋零時反轉，請先看[方向與到位檢查結果](motor_direction_audit_zh_TW.md)。單腳參數沒有覆蓋 Standing 參數，但 L1 的反方向回讀仍需實體核對；新版會辨識並停止這類異常。

用這個控制台就能連線、查看電源、屏蔽腳，以及設定單腳或多腳的角度、速度與相位。一般操作只要選編號，不必背 ROS 指令。

## 1. 怎麼打開

在 **Jetson 終端機**貼上：

```bash
cd /home/jetson/rinbo_ros_ws
./robot.sh
```

開啟選單不會上電。sbRIO 位址已設好，已儲存密碼時會自動登入。
如果舊控制台還開著，先選 **0** 關電並離開，再重新開啟。

**第一次最簡單：主選單 9 → 腳選 2（L2）→ 範例選 1（小轉 +5°）→ 主選單 3 → 輸入 1 確認執行。** 如果 L2 已屏蔽，先用 8 處理，或選另一隻可用腳。

### 人在現場，要一直調整和試轉

1. 選 **14 → 1**，開啟「現場調機」。開啟模式本身不會上電。
2. 選 **2** 設定腳與動作，或 **9** 套用常用動作。
3. 選 **13** 調出力：**1 加 10、2 減 10、3 自行填值、4 採用現場上限**。不用再填另外兩個限制。
4. 看主畫面的腳、速度、時間和出力，按 **3** 就開始；不會再問一次「輸入 1」。若需要校正，仍只校正所選腳。
5. 完成後繼續調整，再按 **3**；也可直接按 **3** 重做。

現場模式中，改設定、換腳、載入收藏都只更新主畫面；**每一次都要由你按 3 才開始**。按 Q 可停止。選 **14 → 2** 可切回一般確認模式；全部關電、執行失敗或取消、進入屏蔽管理、更換網路、現場設定變更及重開控制台，也會回到一般模式。

選 **9** 現在保留你調好的出力、時間和加速度，不會重設出力。只有明確選 **r 入門範例** 才會整組恢復入門設定。

## 2. 主選單找什麼

| 選項 | 做什麼 |
|---|---|
| **1 連線檢查** | 自動停止可辨識的舊動作、整理過期紀錄，沿用／建立通訊並確認新回讀；不上電 |
| **2 選腳與動作** | 三步：用編號選腳 → 填各腳動作 → 填時間；先存設定 |
| **3 執行目前動作** | 自動處理連線、電源，以及本次所選腳的校正，再執行 |
| **4 全部關電** | 關閉電源，保留通訊與選單 |
| **5 角度／零點／狀態** | 看六隻腳的角度、零點訊號、感測器供電、馬達電源與電壓 |
| **6 網路設定** | 修改 sbRIO／Jetson 位址；目前能連線就不必改 |
| **7 出力／加速度／速度上限** | 集中調整三項限制，不用每次設定動作都重填 |
| **8 腳的屏蔽管理** | 查看、屏蔽、解除屏蔽指定腳或全部腳 |
| **9 常用動作** | 用編號套用小轉 +5°、-5°，或每秒正轉／反轉 5°的範例 |
| **13 出力快調** | 加減 10、自行填值、採用現場動作上限；其他參數保留 |
| **15 到位／追蹤限制** | 調整 Calibration／Standing／Tripod 的到位誤差與等待時間，預覽後儲存；詳見[限制設定說明](motion_limits_20260909_zh_TW.md) |
| **14 現場模式** | 開啟後按 3 直接開始；切回一般模式可恢復逐次新動作確認 |
| **10 我的動作** | 把調好的設定取名收藏，下次選用；也可刪除收藏 |
| **11 快速調整** | 反轉方向、半速、兩倍速，或把某腳的動作複製到其他腳 |
| **12 復原上次設定** | 改錯時退回上一份動作設定；不會讓實體腳倒退 |
| **h 說明** | 在控制台內查看教學與快速輸入寫法 |
| **r 入門範例** | 套用一隻可用腳小轉 5°的設定；不會直接執行 |
| **0 關電並離開** | 關電，停止本工具啟動的通訊程序，再離開 |

主畫面按左前、左中、左後／右前、右中、右後排列六隻腳，`*` 標出本次選中腳。上方是連線、馬達電源與電壓，下方有目前動作、最近結果與下一步提示。**可用只是允許選擇，不代表正在通電。**

每次回到主畫面會更新狀態；也可直接 **Enter** 重新整理，不會執行動作。畫面是更新當時的狀態，不是持續刷新的即時監控。

**連線卡住時直接按 1。** 新版會封存前次開機或已退出程序的紀錄，保留原始日誌；正常的 Core、FPGA、Bridge 可以沿用，包括 Windows 啟動的服務。若有可核對身分的 Calibration／Standing／Tripod／逐腳動作，會先正常停止並核對停止回讀。登入電腦不會自動整理，也不會關閉其他人的 SSH、桌面或網路連線。無法核對身分、重複服務或動作未正常停止時，會保留通訊並顯示原因；詳見[連線自動整理說明](connection_recovery_20260909_zh_TW.md)。

**不知道卡在哪裡，就選 5。** 六隻腳各有一行：

- **角度**：由編碼器回讀換算；校正完成後才以校正零點解讀。不是你填的目標角度。
- **零點感測器（Hall）**：依目前校正程式，**0＝已觸發、1＝未觸發**。觸發後仍需停穩及確認編碼器歸零，不代表整個校正流程已完成。
- **未知**：沒有新的有效回讀；不會拿舊角度假裝是現在的位置。

感測器尚未上電時，即使通訊有資料，回報值也不代表有效的實體位置，畫面會另外提醒。

目前機器人的回讀沒有直接提供速度；主畫面顯示的是你設定的速度。選 5 後，詳細資料會留在輸入提示上方，可直接選下一個功能。

## 3. 怎麼屏蔽或解除屏蔽

先選主選單 **8**，就會列出六隻腳：

| 編號 | 腳 | 位置 |
|---|---|---|
| 1 | L1 | 左前 |
| 2 | L2 | 左中 |
| 3 | L3 | 左後 |
| 4 | R1 | 右前 |
| 5 | R2 | 右中 |
| 6 | R3 | 右後 |

每隻旁邊會寫「可用」或「已屏蔽」。位置仍需對照實體接線標籤。

**例如要屏蔽 L3：**

1. 主選單選 **8**。
2. 子選單選 **1：屏蔽指定腳**。
3. 填 **3**，再按 Enter，立即儲存。

**要解除 L3 的屏蔽：** 同樣進 **8**，改選 **2：解除指定腳的屏蔽**，再填 **3**。

一次處理多隻，就用空白隔開編號。例如填 **`1 3`**，代表 L1、L3。選腳時直接 Enter 可取消。

子選單還有 **3 全部屏蔽、4 全部解除屏蔽、5 重新整理、0 回主選單**。全部屏蔽後仍能進控制台，之後再解除要使用的腳。

設定會立即存進原本的共用設定檔，重開仍保留，也會影響其他使用這份設定的 FSM 程式。已連線時，控制台先自動關電再修改，保留通訊；解除屏蔽不會自動上電或轉動。

若目前動作選中的腳被屏蔽，控制台會指出來，讓你用 **2** 換腳或用 **8** 解除屏蔽；不會偷偷換另一隻腳執行。屏蔽限制主馬達，伺服電源仍共用。

## 4. 怎麼讓一隻腳動

先固定機身，讓腳有足夠轉動空間。

1. 看主畫面，確認要測的腳是「可用」。
2. 選 **2**，腳的編號填 **2（L2）**，動作選 **1（小轉一下）**，角度填 **5**，最後時間填 **3 秒**。出力與加速度沿用目前設定，需要調整再選 **7**。
3. 選 **3**，看清楚動作內容後，輸入 **1** 開始；直接 Enter 取消。原本的 **y** 或「開始」也能用。
4. 完成後，同設定再選 **3** 就直接重做；改設定則回 **2**。

只選 L2，就只校正 L2，不等待 L3。屏蔿名單變更、改選尚未校正的腳，或感測器供電／資料中斷後，下次執行會重新確認校正。

選 **3** 後會先列出「本次執行範圍」：哪些主馬達會動、是否需要校正、原因，以及哪些主馬達不參與。校正範圍依你選的腳決定，**不會把「未屏蔽的全部腳」當成本次必須校正的腳**。

| 你的操作 | 校正會怎麼處理 |
|---|---|
| 第一次只測 L2 | 只等待 L2 的伺服到位、零點觸發、停穩與歸零；不等待其他腳 |
| L2 校正有效，只改速度、相位、角度、時間或出力 | 沿用 L2 的校正；一般模式確認後開始，現場模式按 3 直接開始 |
| 已一起校正 L2、R2，現在只測 L2 | 紀錄涵蓋 L2，沿用校正 |
| 改選尚未包含在有效紀錄中的腳 | 重新校正本次所選腳，不加進其他腳 |
| 全部關電、回讀中斷或改屏蔿名單 | 先前紀錄不能直接沿用；下次仍只校正當次所選腳 |

目前一份完成紀錄保存的是**最近一輪成功校正的腳**，不是跨次永久累加。例如先只校正 L2，再只校正 R2，新紀錄只涵蓋 R2；之後回到 L2 會重新確認校正。畫面會說明紀錄是否涵蓋本次的腳。

單腳測試仍使用共用電源與通訊；因此供電或通訊故障仍會停止。未選中的伺服保持回讀位置，不能把「主馬達未參與」理解成那隻腳的伺服已斷電。

校正與測試動作有各自的出力設定。執行摘要會列出現場校正出力上限，避免把你在 **7** 設的測試出力當成校正出力。

執行時會依序顯示五個階段，不必自己開不同程式：

| 階段 | 程式正在做什麼 |
|---|---|
| **1／5 連線** | 確認電腦收到機器人的新資料；還沒上電 |
| **2／5 電源** | 開感測器與馬達電源，確認電源回讀 |
| **3／5 校正** | 只找本次所選腳的零點；可沿用時會明說，不重找 |
| **4／5 動作** | 執行你設定的角度、速度或相位 |
| **5／5 收尾** | 停止主馬達並確認關閉馬達電源 |

校正等待期限會依現場的伺服定位、尋零、停穩與歸零時間計算；不再固定 60 秒。所選腳完成就立即接續；超時會用中文指出是在等伺服、停穩或歸零。原本各階段的停止條件仍生效。

看到「所選腳校正完成」後，程式還會結束校正程序並核對完成紀錄，再進入 **4／5 動作**。已修正這個交接階段提早關閉 ROS、導致 `rcl node's context is invalid` 並取消完成紀錄的問題；不用手動刪除紀錄或更改屏蔿名單。

如果其他控制程式仍在發布馬達命令，選 **3** 會先提示停止該程式，再重新嘗試。本次動作不會因為這個前置檢查失敗就去替其他程式關電；需要全部關電仍可直接選 **4**。

每次填數值都有建議與實際預設值；**直接 Enter 採用畫面顯示的值**，可能是你上次改過的設定。想回到入門值可選 **r**。

填錯時只會重新問那一欄；設定中輸入 **q** 可取消，保留原動作。選 **9** 套用範例時，保留目前的時間、出力、加速度與速度上限；若選每秒 5 度的範例且上限不足 5，才提高到 5。它只存設定，還要選 3 才執行。

選 **7** 時，程式會依目前動作告訴你速度上限至少要多少。例如已設定每秒轉 25 度，就不能把上限填成 10；只需重填速度上限，前兩欄保留。想降低實際旋轉速度，請到 **2** 改動作。

選 **6** 填錯 IP 或通訊埠，也只會重問錯的那一欄。動作、限制與網路設定都在儲存成功後才套用；如果磁碟或檔案權限出問題，會保留原設定並說明原因。

熟悉後也能直接在主選單輸入 `L2 +5`、`L2 v 10`、`time 3` 或 `pwm 20` 快速改設定，再選 **3** 執行。想同時設定多隻腳的不同動作，用選單 **2**。

### 校正能轉，設定每秒 5 度卻不動？

每秒 5 度是「希望它轉多快」；出力上限是「最多允許控制器用多少出力」。慢轉仍需要足夠的力才能起轉。逐腳動作預設上限現已改成 80，仍取動作與現場上限中較小者。上限不是持續出力，控制器依位置與速度誤差調整。

動作畫面會同時列出 **實際角度／速度、目標角度／速度、PWM 命令／上限**。PWM 是送出的控制命令，不是實測電壓、電流或馬達出力。

若載入舊動作設定，同一次開機與接線下校正確實帶動 L2，而動作顯示 `PWM命令=20.0/20.0`、實際角度一直不變，主要懷疑是起轉出力不足。確認腳可自由轉動後，選 **7** 將動作出力由 **20 改成 30** 作一次比較，其他數值沿用：速度 **5 度／秒**、時間 **3 秒**、速度上限 **10**、加速度 **10**；再選 **3**。也可在主選單輸入 `pwm 30`，再選 **3**。30 是比較用的試值，不是已量測的合適出力。

若仍不動，保留新日誌再檢查驅動端；不要把「到上限」當作必須繼續加大的證明。只改出力上限不會自動試轉；選 **9** 會保留出力，選 **r** 會恢復目前入門設定（出力上限 80）。

未到位時，程式會列出目標與實際角度。如果整段編碼器變化小於 0.1 度，而且命令曾達到上限的 95%，會另外指出「命令出力曾達上限，幾乎沒有位置變化」。這是診斷線索，不能單憑它區分出力不足、驅動沒有執行或編碼器異常。

## 5. 調好一次，下次直接選用

例如你已把 L2 設成每秒轉 5 度，希望下次不用重填：

1. 主選單選 **10 我的動作**。
2. 選 **1 收藏目前動作**，取名「L2 慢速測試」。
3. 選 **0** 回主選單。

下次開啟控制台，選 **10 → 2 選用已存動作 → 收藏編號**。畫面會列出完整設定；選 **3** 才執行。

最多可收藏 30 組，包含選中的腳、動作、時間、出力、速度上限及加速度。同名儲存會先顯示原內容，輸入 **1** 才覆蓋。刪除也是先選收藏，再輸入 **1** 確認；刪除不會清除主畫面目前的動作。

收藏不包含屏蔿名單、網路、校正或供電狀態。如果收藏中的腳目前已屏蔽，會標出來並拒絕載入；不會自動解除屏蔽或換成其他腳。

## 6. 快速改方向、速度或換腳

主選單選 **11**，再選：

| 選項 | 範例與效果 |
|---|---|
| **1 反轉方向** | 小轉 +5° 改成 -5°；每秒 +5° 改成 -5°。所有選中腳一起調整 |
| **2 半速** | 每秒 10° 改成 5°，移動速度上限也減半 |
| **3 兩倍速** | 每秒 5° 改成 10°，移動速度上限也加倍 |
| **4 複製到其他腳** | 例如把 L2 的設定換到 R2，目標腳編號填 **5**；填 **2 5** 則兩隻使用相同動作 |

反轉不保證回到上一次的起點；「移到角度」模式要到 **2** 修改目標角度。相位旋轉只反轉速度，起始相位不變。

半速／兩倍速保留目標角度、起始相位、保持／勻速時間、出力與加速度，因此整段動作時間不一定剛好加倍或減半；旋轉模式的轉動總角度也會改變。如果超出既有速度範圍，會保留原設定，提示改用 **2** 或 **7** 自訂。

複製功能會讓本次**只控制新選中的腳**。原本有多種動作時，先選一隻來源腳，再選目標腳。新選中的多隻腳會套用同一份角度／速度／相位；若要不同相位，再用 **2** 分別調整。

## 7. 改錯了怎麼退回

主選單直接選 **12 復原上次設定**。本次開啟控制台後，最多可逐次退回 20 份不同的動作設定；關閉控制台後，這份復原紀錄不保留。

它只復原動作、時間與限制，不會改屏蔿名單、電源或實體腳的位置，也不會重新建立校正紀錄。若退回的設定選到已屏蔽腳，主畫面仍會擋住執行。儲存失敗時不會吃掉復原紀錄，排除問題後可以再選 **12**。

## 8. 怎麼停止

- **校正／動作中按 Q、空白鍵、Esc 或 Ctrl+C**：不用 Enter，停止本次動作並嘗試關電。
- **正常完成**：關馬達電源，保留感測器供電，方便接著測。
- **主選單 4**：全部關電，留在控制台。
- **主選單 0**：關電並結束操作。

軟體停止需要通訊與控制器處理時間；現場的實體斷電仍可直接使用。

想看詳細模式與排錯，查[單腳操作說明](manual_leg_control_zh_TW.md)；原本的屏蔽指令保留在[腿部啟用／屏蔽](orin_multileg_operation.md)。

本次做過哪些確認，見[控制台檢查紀錄](control_panel_validation_zh_TW.md)。
