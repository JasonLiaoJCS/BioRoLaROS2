## 校正完成後交接失敗修正

現場日誌 `20260908-210203-16337` 顯示：L1／L2 各次均已收到歸零並進入 DONE，
但控制台隨後送出的 SIGINT 使 ROS context 提早關閉；尚未結束的 motor/state 或 power/state
回呼查詢失敗，觸發 SAFETY STOP 並使完成紀錄失效。這不是等待其他腳校正。

修正為由校正程式處理 SIGINT／SIGTERM，先停止 executor 派發回呼、送停用命令，
再關閉 node 與 ROS。正常完成保留紀錄；未完成中止及真正的故障仍以失敗退出。
控制台不忽略 DONE 後的錯誤，仍核對退出結果與原生完成紀錄。

- C++ 校正組 12 項通過：含真正送出 SIGINT／SIGTERM 後的 graph 查詢、完成紀錄保留與失效判斷。
- Python 相關回歸 84 項通過：含 DONE 後正常退出、DONE 後仍發生真正故障不能繼續。
- 校正測試只寫自己的暫存 fixture，避免與現場運作程序互相干擾；實機設定修改的占用檢查保持生效。
- 已重新編譯校正程式並更新控制台。依使用者指示停止舊版獨立校正程序 PID 26797，並確認程序退出。
